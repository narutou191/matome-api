Como o usuário preenche o simulador?

Escolha o fluxo que faz mais sentido para corretores e clientes

A

Passo a passo (wizard)

Tela 1: Escolhe situação atual (aluguel ou casa própria)

Tela 2: Preenche despesas atuais uma a uma

Tela 3: Vê resultado MATOME + gera PDF

Vantagens

  • Mais guiado, menos intimidador
  • Ideal para cliente sozinho

Desvantagens

  • Mais cliques até o resultado
B

Página única (tudo visível)

Todos os campos na mesma tela

Resultado aparece ao lado em tempo real enquanto digita

Botão "Gerar PDF" sempre visível

Vantagens

  • Mais rápido — corretor preenche ao vivo
  • Cliente vê comparativo em tempo real

Desvantagens

  • Pode parecer muito denso no celular
C

Híbrido

Formulário à esquerda (todos os campos visíveis)

Resultado dinâmico à direita (desktop) ou abaixo (mobile)

No celular vira passo a passo automático

Vantagens

  • Desktop: poderoso para o corretor
  • Mobile: fluido para o cliente

Desvantagens

  • Mais complexo de implementar
